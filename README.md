# Agent Metrics

Local-first metrics dashboard for Claude Code and future agent adapters.

## Commands

- `corepack pnpm install`
- `corepack pnpm test`
- `corepack pnpm --filter @agent-metrics/core dev`
- `corepack pnpm --filter @agent-metrics/dashboard dev`
- `corepack pnpm --filter @agent-metrics/cli dev -- wrap node --version`
