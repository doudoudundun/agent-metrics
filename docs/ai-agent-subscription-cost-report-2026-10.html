一统一口径：什么才能被比较

各家定价的计量单位完全不同——WorkBuddy 用积分、OpenCode 用美元额度、Cline 用「几倍 API 价」、其他国内平台用自家 Credits。直接比月费没有意义，必须先归一。

1.2 「杠杆」的定义

杠杆倍数 = 套餐提供的额度（按官方 API 零售价折算成美元）÷ 实付月费（美元）

杠杆 8.0x 意味着：你花 $10，拿到值 $80 官方价的 token。这是唯一能跨积分制／美元额度制／「N 倍 API 价」制比较的单位。官方直充的杠杆定义为 1.0x。

已知局限：只有「额度按美元计价」的平台能精确算杠杆。智谱、Trae、Qoder、Kimi、腾讯云 Token Plan 等卖的是自家模型，credit→token 比例不公开，只能按「同价位谁给得多」定性比较，不进入总表。

二WorkBuddy 积分定价解构

2.1 积分 = token 成本的线性折算

对 927 条带 providerData.rawUsage.credit 的真实记录拟合 credit = a·miss + b·hit + c·out，得到每 100 万 token 的积分系数：

token 类型积分 / 1M tokenDeepSeek 官方高峰价反推 ¥ / 1M token
输入 · 缓存未命中28.17¥2.00¥1.97
输入 · 缓存命中0.5045¥0.04¥0.035
输出115.06¥8.00¥8.05

三者比例 hit : miss : out = 1 : 56 : 4.08，与 deepseek 官方高峰价卡的 1 : 50 : 4 几乎重合。这意味着积分就是按官方高峰价卡折算出来的，可以直接相除：

  • 2 元 ÷ 28.17 = ¥0.0710 / 积分
  • 8 元 ÷ 115.06 = ¥0.0695 / 积分
  • 逐条实测中位 = ¥0.0701（p10–p90 = 0.0678–0.0740），聚合 = ¥0.0731

结论：积分单价恒为 ¥0.07，与时段无关

注意一个反直觉现象：不算签到时，包月价下反而是旗舰版杠杆最高（5.08×）、标准版最低（4.06×）——因为高级和旗舰的赠送比例更厚（高级赠 5,000/基础 4,000，旗舰赠 30,000/基础 20,000，标准版只赠 2,000/基础 2,000）。是那 3,000 签到积分把排序重新翻了过来：标准版 +75%、高级 +33%、旗舰 +6%。

签到对越小的套餐越值钱：标准版 +75%，旗舰版只有 +6%

原因很简单：3,000 在标准版 4,000 里占 75%，在旗舰版 50,000 里只占 6%。所以「买最小档 + 每天签到」是 WorkBuddy 里杠杆最高的使用方式，而不是买大套餐。

满勤口径更高：30 天按 7 天循环约 4 轮周礼包，签到可拿 6,600/月，标准版合计 10,600 积分 ≈ 10.8×（连续包月价）。但断签一天就丢掉当周 1,000，所以本报告基准取保守值 3,000。

一个容易误解的点：包年不等于「一次性拿到 12 个月额度」

基础积分与赠送积分有效期都是 1 个月，签到积分按月结算。所以包年只是把月费降到 ¥56，额度仍然是每月 4,000（+签到 3,000）刷新、当月用完，不能攒、不能一次性刷 84,000 积分做长期项目。判断够不够用，始终要按月看。

国际版在同一价位上只有国内的一半额度

所以对国内用户来说，国际版不存在「海外更划算」的情况，除非你在境外结算或确实需要国际站点。之前把国际年付算成 WorkBuddy 最优档，是因为漏了国内这 100/天和连续包月折扣。

四按固定用量的绝对成本

4.1 单买一个平台

杠杆高不等于总支出低——如果额度小到不够用，就得买加量包补，单价立刻崩掉。所以更该看的是：达成同一个用量目标，每月实际掏多少钱。

你 10-20 的强度折算为月度：145.1 积分/天 × 30 = 4,350 积分 ≈ $43.5 官方 API 价，对应约 28.3 亿缓存命中 + 4,530 万缓存未命中 + 1,266 万输出 token 的混合结构（按当日实测分布等比放大）。

官方定价页把四个版本逐项列了出来。关键在于：体验版大部分能力差距目前都被「限免」兜住了，只有一项没有。

关于 CLI：官方表格写「不支持」，但这一条存在第二种可能性，别急着下结论

官方写法是确定的：WorkBuddy 定价页的「CLI 访问支持」一栏，体验版是「—」，标准版起是「✓」。这是四个版本里唯一没有被「限免」兜住的差异。

但它没说清是哪个 CLI。而 CodeBuddy 的定价页（同一套账号体系、积分共享）根本没有这一行。第三方资料的说法与之相反——「CLI 是产品的另一种形态，账号体系与 IDE 共用，订阅方案对 IDE 和 CLI 通用，免费版额度同样适用于 CLI」。两条信息冲突，官方文档没有给出可引用的澄清。

一种合理的解读：这一栏指的是「能否通过 CLI 访问 WorkBuddy 侧的能力」，而不是「CodeBuddy Code 这个 CLI 能不能跑」。若是后者，CodeBuddy 定价页不该省略这一行。

30 秒可以自证：终端执行 codebuddy → /login 登录 → 发一条极短 prompt（消耗不到 1 积分）。能出结果就是可用；若返回额度或套餐相关报错，就是被限制。实测本机 codebuddy CLI 已装（v2.170.0），但需要独立 /login，桌面端的登录态不会自动共享。

但有一点绕不过去：就算 CLI 能用，它烧的是同一个积分池

官方明确「WorkBuddy 和 CodeBuddy 同一账号积分共享，无需分别订阅」，而 CLI 的模型列表里就有 deepseek-v4.1-flash。所以「用 CodeBuddy CLI 绕过限制」只在「CLI 权限被单独锁死」的情况下成立；如果锁的是积分，绕不过——体验版 500 积分跑 CLI，几轮就用完了。

这也是为什么下一节的判断要分开看：权限可能是可绕的，额度不可绕。

所以真正的分水岭只有一个问题：你的额度够不够

只用桌面客户端、CLI 也用不上 → 体验版的实际能力约等于标准版，只差额度。那 体验版 + OpenCode Go 的组合确实最优，11.5× 对 7.10×。

要在终端跑 agent、接 hooks、做自动化 → 先花 30 秒自证 CLI 能不能在体验版下跑。能跑，就仍走体验版 + Go；不能跑，那 ¥70 买的是「CLI 权限 + 额度不断档」两样东西，而不是单纯买积分。

还有两个隐性成本，量化不了但要算进去

① 额度墙提前到达，而且补不了。体验版 3,500 积分对你 4,350/月的强度只够 24 天，月末约一周会「WorkBuddy 用不了」。更麻烦的是加量包只有付费会员（标准版及以上）能买，体验版没有补救通道——用完了只能等签到累积或等下月刷新，或者把活挪到外部平台。标准版 7,000 则始终有富余。

② 双工具的心智开销。WorkBuddy 强在生态（文档、企微、资料库、桌面 agent），Go 只是模型通道。两边任务分工一旦模糊，你会反复判断「这活该在哪跑」，这个成本不进账本但真实存在。

③ 「限免」是活动，不是条款

上面标「已抹平」的四项——无限补全、99 个自动任务、全模型可选、5 人协作——都是限时免费名额，官方页面写的是「部分功能限免生效中」。一旦结束，体验版会退回 3 个自动任务 + Auto 调度（不能选全模型），而标准版的差距会立刻扩大。所以「体验版 ≈ 标准版」这个判断有时效性。

六结论与建议

①如果 90% 用量的模型就是 deepseek-v4.1-flash

三家已经打成平手：OpenDesign Go 年付（17.1×，¥50/月）绝对价格最低，但 5h $10 + 7 日 $30 双窗口很紧，连续大重构容易卡住；OpenCode Go（8.0×，¥71/月）额度 $80、窗口最宽松，但只有模型池没有产品；WorkBuddy 国内标准版连续包月（7.10×，¥70/月）价格和 Go 只差 ¥1，额度 7,000 积分对你 4,350/月的强度富余 61%，还带完整桌面产品。

②如果要 WorkBuddy 的产品体验 —— 先回答一个问题：用不用 CLI

CLI 被锁、或不能接受月中断档 → 买标准版，选连续包月，每天签到。三项加起来 7.10×（¥70/月）；愿意年付 ¥672 就到 8.88×（¥56/月）。高级版（¥140）属于多花 ¥70 买余量，旗舰版 53,000 积分严重过配。国际版不要买：和国内包年同价（¥57 vs ¥56）却只给一半额度，补包单价 0.33× 是全表最差。

CLI 能跑，且能接受两套工具 → 别急着付这 ¥70，看 ⑤：体验版 + OpenCode Go 是 11.5×，同样的钱多拿 64% 额度。

③如果要多模型（Claude / GPT）

WorkBuddy 全模型可选，是这一项上的优势（体验版在限免期也放开全模型）；DevPass 虽有官方直连但杠杆只有 2.0×，且刚从 3× 降档，属于正在缩水的通道。两者都谈不上便宜，这一档本质是在为「模型可得性」付溢价。

④不换平台就能拿的三笔钱

按效果排序：① 选连续包月（7 折，可随时取消）——零成本，立刻 +40% 杠杆；② 每天签到——标准版 +75%，但需手动领、断签丢当周 1,000，建议设个定时提醒；③ 批量任务错峰——闲时半价，同一份工作量的积分消耗直接减半（今天 145.1 积分的活放闲时只要 75.7 积分）。三条都不需要换平台，也不用改变用法。

⑤如果愿意维护两套工具：体验版 + OpenCode Go 才是数字最优

体验版 500 基础 + 签到 3,000 = 3,500 积分（$35）零成本，配 Go 的 $80，¥71 换 $115 额度 = 11.5×，比标准版连续包月的 7.10× 高 62%。唯一的变量是 CLI：官方权益表标注体验版不支持，但 CodeBuddy 定价页没有这条限制、第三方资料也说「免费版额度同样适用于 CLI」——两者冲突，最稳妥的方式是自己 /login 后跑一条 prompt 验证。不过即便 CLI 可绕，积分池是同一个，500 积分撑不了几轮，所以真正会逼你付费的仍然是额度而不是权限。

7.2 四个必须说明的不确定性

① 积分→token 的折算系数是反推的，不是官方公布的

28.17 / 0.5045 / 115.06 这三个系数来自对真实计量记录的线性回归，无法看到平台内部价卡。它的可信度来自两点交叉验证：比例与 DeepSeek 官方高峰价卡高度重合（误差 <2%）、拟合中位相对误差 6%。但若平台更换折算价卡，这套数字会整体平移。

② 额度数字只能当「上限」读，不能当「保证」读

OpenDesign 的 $120/$160 是 model-specific usage equivalent 口径；OpenCode 的 $80 是文档标示值；Cline 完全不公开。这类「用批量折扣补贴开源模型」的套餐，历史上已多次调整：Cline 砍过 4 个模型，DevPass 10-15 从 3× 降到 2×，智谱 8 月涨价 130–260%。结论只对 2026-10 这个时点成立。

③ 年付要谨慎，但连续包月没有这个风险

OpenDesign 年付 17.1× 是全书最高值，WorkBuddy 连续包年 8.88× 也很高，但两者的前提都是「额度、折扣、模型名单在一年内不变」——这个前提在 2026 年已被反复证伪（DevPass 从 3× 降到 2×、智谱涨价 130–260%、Cline 砍模型）。

建议先用「连续包月 + 签到」这个组合：7.10×，随时可取消，跑一个月确认额度够用再决定要不要转包年。这样既拿到 7 折，又不承担承诺风险。

④ 促销赠送与签到政策是「限时活动」，不是合同条款

标准版的 2,000 赠送积分、每日签到 100/第 7 天 1,000，都属活动性质（早期签到曾只有 5–20 分/天）。若赠送取消，标准版额度从 7,000 回落到基础 2,000 + 签到 3,000 = 5,000，杠杆降到约 5.1×——仍高于官方直充，但会低于 OpenCode Go。本报告的 8.9× 是「当前活动全部命中」的乐观值，5.1× 是它的下限。
